## Мои проекты

### [TUInk](https://github.com/kosatchev/TUInk)

Текстовый редактор в терминале с привычными сочетаниями клавиш, мышью, меню и вкладками. Когда хочется привычного редактирования, или просто слишком ленив, чтобы выучить VIM. Попутно разбираюсь с терминальными интерфейсами, Unicode и восстановлением после сбоев.

### [BOSS-Dict](https://github.com/kosatchev/BOSS-Dict)

Личный форк [OSS-Dict](https://github.com/Akylas/OSS-Dict) для офлайн-словарей на Android. Развиваю поддержку Lingvo DSL/DSL.DZ, импорт и работу с коллекциями словарей. Задача — продолжать пользоваться своими словарями на современных устройствах.

### [ml-compose](https://github.com/kosatchev/ml-compose)

Обёртка над Docker Compose для рабочих ML-задач: проверка конфигурации запуска, учёт владельцев проектов и координация использования GPU. Инструмент для общего сервера, чтобы уменьшить случайные конфликты между запусками.
